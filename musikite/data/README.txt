Leland.ttf: the SMuFL music font Leland (MuseScore), SIL Open Font License 1.1
(https://github.com/MuseScoreFonts/Leland). It is the subset shipped by Verovio
(verovio/data/Leland.css, woff2) converted to TrueType. Used by engrave.py to
write noteheads, rests, clefs, accidentals, ... as text in PDFs.
